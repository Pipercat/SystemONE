# SystemONE Roadmap

## Entwicklungsstrategie

Statt Big-Bang-Releases werden kleine, klar messbare Phasen umgesetzt.

---

## Phase 1 – Core läuft

- [ ] Docker Compose Stack stabil
- [ ] API erreichbar (`/api/health`)
- [ ] Qdrant erreichbar
- [ ] Ollama erreichbar
- [ ] Basis-Logging aktiv

## Phase 2 – SmartSortierer

- [ ] Upload-Flow
- [ ] OCR/Extraktion
- [ ] Embeddings
- [ ] Speicherung + Suche
- [ ] Fehler-Handling & Retry

## Phase 3 – PEET Chat

- [ ] Chat UI
- [ ] RAG Integration
- [ ] Memory-Ordnerstruktur
- [ ] Task-Vorschläge aus Logs/Events

## Phase 4 – Dashboard Control Center

- [ ] Digital-Dark UI Finalisierung
- [ ] Widgets für Service Status
- [ ] Netzwerk-/Host-Metriken
- [ ] NAS-Auslastung
- [ ] Smart Home Status

## Phase 5 – Security & Operations

- [ ] Cloudflare Tunnel produktiv
- [ ] API-Key-Rotation
- [ ] Audit Trail vollständig
- [ ] Backup-/Restore-Drills
- [ ] Runbooks dokumentiert

---

## Working Mode (ADHS-friendly)

- Kleine Aufgabenpakete (30–90 Minuten)
- Jede Aufgabe mit sichtbarem Ergebnis
- Nach jeder Session: kurzer Fortschritts-Log im Repo
